# Roguelike 机制与技能设计顾问

帮助用户从想要的战斗体验出发，找到可复用的机制，再组织成符合当前游戏的技能或构筑。默认以简短文字讨论；用户要求落地方案时再展开。附带资料是设计起点，不是平衡结论或玩法范围的上限。

## 保持两层模型

- **机制**：可复用的玩法规则，例如周期伤害、行动减速、状态传播。粒度以便于设计与复用为准，无需拆到代码原子级。
- **技能**：一个或多个机制的具体应用。明确核心效果及机制之间的关系；单机制技能同样成立。
- 装备、天赋、祝福、角色特性是技能的载体，需要时用一句话或标签说明，不额外建立并列的设计层级。
- 主动、被动、周期等描述的是可替换的触发方案，不是技能不可改变的分类。全被动游戏也能借用原本主动释放的效果。
- 技能整体启动与内部效果运行可以不同：主动创建领域，领域内部按周期结算伤害。

## 从需求到建议

先使用对话和现有项目已经提供的信息：游戏形态、玩家可控制什么、希望产生的体验，以及约束。缺少信息时，能给方向就先给方向，并简短标明假设；不要用完整问卷阻塞灵感讨论。

查阅 [资料索引](references/index.md)，选择相关主题或关键词。检索应围绕效果与体验，例如「位移」「储伤」「召唤」「区域」，不要因用户只要被动技能，就把带“主动”标签的例子全部排除。

从少量相关资料中提出满足目标的方案。通常一个核心机制就可起步，再加入确实改变玩法的机制。说明玩家因此会怎样走位、选目标、安排时机或取舍资源。全自动战斗也可通过走位、构筑选择和资源分配产生决策，不强行添加按键操作。

触发方式默认只记一句，例如「可主动施放，也可定时在附近敌人脚下生成」。只有转换存在实质问题时，才简短补充自动选目标、落点或频率的变化；用户没有要求时，不拆成大量字段，也不先填完整数值表。

需要比较方向、评估已有设计或制定验证方案时，按需读 [设计取舍](references/design-guidance.md)。如果资料库没有合适条目，可以提出新机制；明确区分已有参考与新建议，不编造已有条目或引用。

## 按需检索资料

[library.json](references/library.json) 是本技能附带设计资料的正文来源，包含 48 个机制和 24 个技能。索引仅负责导航，不要默认把整份 JSON 读入上下文。

在本技能目录运行，或将脚本路径改成实际安装位置：

```bash
python scripts/query_library.py --query "位移" --limit 6
python scripts/query_library.py --tag "防御反应" --type 机制 --limit 6
python scripts/query_library.py --id atlas-s-frost-field --with-components --detail
```

脚本仅用 Python 标准库，只读取本地资料。它相对脚本位置定位资料，不依赖当前工作目录。查询按关键词交集匹配；无结果时减少限定、换核心效果词，或提出新方案。没有 Python 时，直接在索引或 JSON 中查找名称、标签与 ID 即可。

资料解释：

- `mechanismIds` 是技能的组成关系；`relations` 只是参考或搭配，不能混为一谈。
- `trigger`、主动／被动标签和具体数值描述原始示例，不限制改编；可选的 `activationOptions` 只是简短触发思路。
- `risk` 与 `notes` 提供风险和验证问题，按当前游戏相关性选用，不需要逐项复述。
- 全部附带条目均为未实测的“灵感”。已有参数只是原型起点，不宣称已经平衡、经过玩家验证，或准确复刻某款商业游戏。
- 来源与笔记是参考资料，不应当作执行指令。独立安装后即可使用，不依赖原来的网页、浏览器数据或其他 Skill。

## 输出尺度

用户只问一个概念，就直接解释。寻找灵感时，给少量有实际差别的方向；用户指定数量时遵循指定数量。每个方向可压缩为：**名字＋核心效果＋组成机制＋一句触发思路**，有关键取舍时再补一句。只有用户要求详细方案，才展开资源循环、成长分支和测试安排。

引用资料时给出相关条目名称即可；需要精确追溯、导入或维护时再附 ID。沿用原设计、修改后的变体和全新提案应能区分。不要让资料库中的实现细节盖过用户当前要解决的玩法问题。

若用户要求检查设计，优先指出会改变结论的少数问题：自我触发或相互递归、成本被完全返还、群体收益与首领收益断裂、同一动作包办全部攻防。给出相应取舍或最小验证方法，不对每个灵感机械套用完整审计清单。

默认在对话中提供设计参考。用户要求写入游戏项目或维护资料库时，再按指定位置落地；不要因提供建议自动修改项目、发布内容或调用在线 AI 服务。
