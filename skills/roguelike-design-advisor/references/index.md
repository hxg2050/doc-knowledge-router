# 机制与技能资料索引

此索引用于按需选取资料，正文以 [library.json](library.json) 为准。包含 48 个机制与 24 个技能，均为原创设计草案，阶段为「灵感」，未经游戏实测。由个人机制图鉴的「基础扩展Ⅰ」整理，作为可移植的静态副本；不会读取或同步个人浏览器资料。

主动／被动等标签描述原示例，不限制技能改编。想做全被动游戏时，先按核心效果检索，再调整触发方式。

## 问题与主题

| 想解决的问题 | 优先查看的主题 | 搜索词例子 |
| --- | --- | --- |
| 设计不同输出节奏、清场或收尾 | 伤害状态、连锁触发 | 周期、层数、引爆、斩杀、传播 |
| 让射击具有覆盖和站位选择 | 弹道目标 | 穿透、弹射、分裂、回旋 |
| 让移动和战场位置影响技能 | 空间移动、召唤场景 | 位移、区域、牵引、地形 |
| 增加防御决策或反击机会 | 防御反应 | 格挡、护盾、承伤、反击 |
| 设计能量循环与操作节奏 | 资源节奏、连锁触发 | 充能、返还、交替、阈值 |
| 让召唤物可经营而非纯自动 | 召唤场景 | 指令、融合、献祭 |
| 创造有代价的强化与成长 | 风险成长 | 诅咒、借贷、衰减、形态 |

命令中的脚本路径相对本 Skill 目录；也可使用安装后的绝对路径。

```bash
python scripts/query_library.py --query "周期 伤害" --limit 4
python scripts/query_library.py --id atlas-s-frost-field --with-components --detail
```

关键词按交集匹配，`--tag` 精确匹配且可重复。`--id` 可重复，与搜索筛选分开使用；`--with-components` 只追加组成机制，不展开普通关联；`--format json` 返回完整匹配内容供程序使用。

## 机制目录

### 伤害状态

| ID | 名称 | 用途 |
| --- | --- | --- |
| `atlas-m-periodic` | 周期伤害 | 把一次伤害预算分配到后续多个时间点，允许玩家挂上效果后转移目标。 |
| `atlas-m-stack` | 层数累积 | 把连续行动积累成可见进度，使多次命中具有共同目标。 |
| `atlas-m-detonate` | 消耗式引爆 | 消耗已有状态或层数，换取一次即时效果，形成现在兑现还是继续积累的选择。 |
| `atlas-m-execute` | 斩杀判定 | 对接近死亡的目标强化收尾，鼓励选择击杀顺序。 |
| `atlas-m-stored-damage` | 伤害储存 | 把已发生事件的一部分伤害记入独立储池，等待玩家释放。 |
| `atlas-m-slow` | 行动减速 | 降低指定行动的完成速度，为走位、瞄准或区域伤害创造时间。 |
